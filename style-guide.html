Credo Legal

Design system

Visual language for the start.credolegal.com redesign. Tokens are CSS custom properties defined in shared/style.css and consumed everywhere downstream — the 36 LPs, the 6 angle-themed variants, and any future page. Swap a token, every page changes.

Typography

Inter, weights 400 / 500 / 600 / 700, loaded from Google Fonts. Sized via CSS custom properties; mobile defaults at the root, desktop sizes override at min-width: 768px.

Trust band

Three social-proof widgets approximating BBB, Trustpilot, and Google Reviews. Real embeds replace these once compliance review clears (May action items §4).

Two placements per LP: above the body sections (without metrics) and after How Our Program Works (with the metrics row).

Illustrations

Brand-coordinated SVG illustration system. Seven motif families: hero (architectural columns), shield (Why Choose), document (Common Problems), people (Who This Helps), book + gavel (Your Rights), conversation (FAQ), process (How It Works). Each motif picks a brand-coordinated palette by hash so the same caller always gets the same color treatment.
