Six angle-themed website variants

Each variant is a complete website (home + about + 6 service pages) themed around one rhetorical angle. All six share the same chrome (header, footer, D3 layout, sticky CTA, Tidio integration per brief 4). What differs between variants: the homepage hero copy and which LP fills each service-page slot. For each variant, every service page picks the cluster's LP that best matches the variant's anchor angle.

The 36 LPs from the live captures fill the slots. Where a cluster has no perfect angle match, a best fit badge appears (yellow). The Medical Debt × Respond-in-Time slot uses the coming-soon placeholder (red) for the 404 URL /medica-debt-lawsuit-respond.
