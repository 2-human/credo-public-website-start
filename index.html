What's the same across all three

The header nav has the same shape: Home / Services (dropdown with 6 clusters) / About. The mobile drilldown menu carries the same items. The footer (utility links + phone numbers + disclaimer) is identical. The locked LP layout from brief 4 applies in all three: sticky CTA bar with same-row Tidio launcher, trust marks band, mobile-first responsive at 768px. Each option's about page is identical.

What's different per option

The Services dropdown in the nav links to the same 6 cluster slugs across all three (e.g., /services/harassment). The page that renders at that URL differs:

  • A — Overview: a browse-oriented overview of the cluster. Intro paragraph, list of sub-services, light contact form. The visitor self-classifies before engaging.
  • B — Champion LP: the cluster's champion LP. Conversion-focused hero, multi-step form, full LP body. Built to convert immediately.
  • C — Hybrid: champion hero plus a visible "all options in this cluster" menu further down the page. Champion-first, browse-second.

The home page also differs subtly: cluster tile microcopy varies by option to set the visitor's expectation about what they'll land on.

How to test

Open each prototype's home page and click through to a service. Compare what happens between A, B, and C on the same cluster (e.g., open a/services/credit-card.html next to b/services/credit-card.html next to c/services/credit-card.html — three browser tabs). Each variant ribbon at the top of every page lets you switch options on the current page without going back to this hub. Use your browser's device emulator at 390×844 (iPhone-class) to check the mobile-first design.
